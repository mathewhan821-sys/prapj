# PRAPJ public project showcase

A static English website presenting the proposed Project Research and Practice Journal and the capstone project behind it. The Journal and Project review modes provide two ways to read the same publicly accessible package.

## Run or publish

Open `index.html` locally, or publish the contents of this directory as the root of a GitHub Pages site. Keep `assets/`, `documents/`, the three JavaScript files and `styles.css` beside `index.html`. No installation, build process, backend or API key is required. Hash routes such as `#/authors` work without server-side rewrites. `.nojekyll` enables direct static-file publication.

## What is included

- Reader and author information, proposed review policies and interactive preparation tools.
- Project evidence, hypothetical financial scenarios, prospective governance discussion and labelled design specimens.
- All eight supplied Word documents, unchanged, plus searchable section-by-section readers.

## Publication status and visibility

This is a public project showcase, not an operational journal submission service. Submissions remain closed. Policies, appointments and publishing arrangements remain proposed; every listed candidate is unappointed. Financial scenarios are hypothetical, with no approved project budget or committed journal funding asserted. Final deliverable acceptance, physical print proof and schedule verification remain pending in the supplied project status.

Everything included here is publicly accessible after deployment, including the project-review material, candidate discussion, source-document text and original Word downloads. The reading modes are navigation, not access controls. The original sources preserve their drafting instructions and internal notes as source content; those do not confer publication approval. Do not add confidential completed forms, private correspondence, credentials or personal contact details.
